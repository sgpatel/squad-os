@Pipeline + @Step ← NEW

@Agent(role = AgentRole.STRATEGIST, name = "MentionPipeline", description = "...")
@Pipeline(
    name     = "mention-analysis",
    failFast = true,
    steps    = {
        @Step(role = AgentRole.ANALYST,  name = "sentiment"),
        @Step(role = AgentRole.CRITIC,   name = "escalation"),
        @Step(role = AgentRole.SUPPORT,  name = "ticket",
              inputFrom = "escalation",
              condition = "contains(\"P1\") || contains(\"P2\")"),
        @Step(role = AgentRole.WRITER,   name = "reply",
              inputFrom = "sentiment",
              condition = "success && contains(\"NEGATIVE\")")
    }
)
public class MentionPipelineAgent {}

PipelineResult result = ctx.submitPipeline(AgentRole.STRATEGIST, "mention text");
result.get("sentiment").content()   // per-step output by name
result.finalOutput()                // last executed step's content
result.succeeded()                  // all steps passed (skipped ≠ failed)
result.failedStep()                 // name of failed step or null
result.skippedSteps()               // List<String> of skipped step names
result.totalTokens()                // sum across all steps
result.wallClockMs()

ConditionEvaluator ← NEW — evaluates @Step.condition() expressions

Predicates:   contains("x")  notContains("x")  startsWith("x")  endsWith("x")
              matches("regex")  isEmpty  isNotEmpty  success  failure
Compound:     expr1 || expr2    expr1 && expr2   (left-to-right, short-circuit)

PipelineEngine ← NEW — sequential step executor

Step 0 always receives original input

Step N (no inputFrom) receives output of step N-1

Step N (inputFrom="name") receives output of named prior step (fallback: original input)

Condition false → AgentResponse.skipped() recorded, pipeline continues

failFast=true + step failure → PipelineResult.failure() returned immediately

DurableEngine — checkpoints after every step

ctx.submitDurable(AgentRole.ANALYST, "claim-2024-9821", input)
// JVM restart → call again with same workflowId → resumes from last completed step
// COMPLETED workflows return cached result immediately (idempotent)

RetryEngine — wraps callLlm() only

Non-retryable: RateLimitExceededException, GuardrailException, AgentSecurityException

Circuit breaker onFailure() called only after ALL retries exhausted

RetryExhaustedException carries agentName, attempts, totalElapsedMs, last cause

GuardrailEngine — pluggable filter SPI

// Custom filter
public class CompetitorFilter implements GuardrailFilter {
    public FilterResult apply(FilterContext ctx) {
        if (ctx.text().contains("RivalBank"))
            return FilterResult.violation("Competitor mention", "RivalBank",
                1.0f, GuardrailAction.BLOCK_AND_LOG);
        return FilterResult.pass(ctx.text());
    }
}
